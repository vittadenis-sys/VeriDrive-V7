# Check Viaggio — V1 product definition

Check Viaggio is a distinct service from VeriScore.

- No VeriScore is generated.
- Workshop uses a shorter safety-focused checklist.
- Result is an Indice Affidabilità Viaggio from 0 to 10.
- 9.0–10.0: Viaggio consigliato.
- 7.0–8.9: Idonea con piccole attenzioni.
- 5.0–6.9: Da controllare prima di partire.
- 0.0–4.9: Viaggio sconsigliato.
- The service is marketed both to existing car owners and before long trips/holidays.
- The public communication must clearly distinguish the travel index from VeriScore 0–100.
